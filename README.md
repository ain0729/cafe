# SHIM — 카페 주문 웹사이트

SHIM은 ‘쉼’이라는 뜻을 담은 카페 주문 웹사이트입니다. 카페 공간과 메뉴를 둘러보고, 음료를 담아 주문 상태와 스탬프를 확인할 수 있는 팀 과제입니다.

**[SHIM 시연 사이트 열기](https://cafe-production-9911cd56.up.railway.app/)**

## 시연 순서

1. **공간**과 **메뉴판**을 둘러보고 **주문하기**에서 원하는 음료를 선택합니다.
2. 온도, 사이즈, 수량을 고른 뒤 장바구니에 담습니다.
3. 시연용 계정으로 회원가입·로그인하고 **시연용 주문하기**를 누르면 주문번호가 발급됩니다.
4. **주문 내역**에서 본인의 시연 주문을 **주문 완료 → 준비 중 → 준비 완료** 순서로 바꿉니다.
5. 음료 10잔을 주문한 뒤 **적립현황 · 쿠폰함**에서 기본 아메리카노 HOT 또는 ICE 한 잔으로 교환합니다. 디저트와 쿠폰으로 교환한 음료는 스탬프 적립 대상에서 제외됩니다.

공개 사이트는 시연 모드로 동작하며 실제 금액을 청구하지 않습니다. 시연 기록은 별도의 SQLite 파일에 저장됩니다.

## 로컬에서 실행

Node.js 24 이상이 필요합니다. 추가 패키지를 설치할 필요는 없습니다.

```powershell
git clone https://github.com/ain0729/cafe.git
cd cafe
npm.cmd start
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. Windows에서는 `start.bat`을 실행해도 됩니다. 종료하려면 서버 창에서 `Ctrl+C`를 누릅니다.

로컬에서도 시연용 주문을 사용하려면 서버를 시작하기 전에 아래 명령을 실행합니다.

```powershell
$env:SHIM_DEMO_ORDERS='true'
npm.cmd start
```

일반 모드는 `data/cafe.sqlite`, 시연 모드는 `data/cafe-demo.sqlite`를 사용합니다. 데이터 파일과 비밀키가 담긴 `.env`는 Git에 올리지 않습니다.

## 개발 스택과 코드

| 구분 | 기술과 파일 |
| --- | --- |
| 화면 | HTML, CSS, JavaScript. `public/`에 페이지와 이미지, `public/menu.js`에 메뉴와 가격이 있습니다. |
| 서버 | Node.js. `server.js`에서 회원 인증, 주문 API, 결제 설정을 처리합니다. |
| 데이터 | SQLite. `store.js`에서 서버 기준 금액 계산, 순차 주문번호, 스탬프 적립과 쿠폰 차감을 처리합니다. |
| 배포 | Railway |
| 테스트 | `npm test`로 인증, 금액 검증, 중복 주문, 주문 상태, 쿠폰 교환을 확인합니다. |

시연 주문은 같은 요청 키가 다시 들어오면 기존 주문을 반환합니다. 무료 쿠폰 주문 생성과 스탬프 차감은 한 트랜잭션에서 처리합니다.

## 결제 연동

프로젝트에는 토스페이먼츠 결제창 API 연동이 포함되어 있습니다. 테스트 결제를 사용하려면 시연 모드를 끄고 `.env.example`을 참고해 `.env`에 같은 상점의 테스트 클라이언트 키와 시크릿 키를 설정합니다. 실제 결제에는 운영 키와 HTTPS 배포 환경이 필요합니다. 자동 테스트에서는 결제사 응답을 모의합니다. [토스페이먼츠 개발자 문서](https://docs.tosspayments.com/)
